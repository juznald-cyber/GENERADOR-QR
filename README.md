# QR Studio Pro — Plataforma Privada de Códigos QR Dinámicos

Plataforma web y móvil (PWA) para generar, personalizar y administrar **códigos QR dinámicos** que **nunca caducan** a menos que el administrador los pause o elimine.

## Características
- **Acceso Privado (Login):** Inicio de sesión con usuario y contraseña mediante Firebase Authentication. El registro público está desactivado.
- **QR Dinámicos Permanentes:** Compatibles con YouTube, TikTok, Instagram, Facebook, Google Drive, Dropbox, OneDrive y cualquier sitio web. Puedes cambiar el enlace destino en cualquier momento sin reimprimir el QR.
- **Personalización Total:** Colores, degradados, formas de módulos y esquinas, carga de **cualquier logo** (PNG, JPG, WebP, SVG) o íconos rápidos, con corrección de errores **Nivel H (30%)** y verificador de contraste para asegurar 100% de escaneabilidad.
- **Exportación HD:** Descarga en PNG de alta resolución (1600×1600) y SVG vectorial.
- **Modo App Móvil (PWA):** Interfaz adaptada para celulares con barra de navegación inferior e instalable en pantalla de inicio.
